# 備用：背景一瞥

遊戲裡每個角色一週只「注意到」兩次（結尾對照頁用的那一次，和之後會在自己故事裡再遇到那個人的那一次）。
下面是拿掉的其他背景一瞥和小回應，內容都對照過對方的劇本，可以當進班討論的素材，或以後再加回遊戲。

## 阿哲

### 週一（你注意到：品妤）

- 一瞥：下課時，你看見欣儀和佳佳手牽手走出教室，把品妤留在後面。　💭 心裡想：她們吵架了嗎？
  - 對品妤揮揮手。 → 品妤看了你一眼，也輕輕揮了一下手。
  - 經過她旁邊時，扮一個好笑的鬼臉。 → 品妤愣了一下，嘴角好像動了一點點。
  - （沒做）抓抓頭，走回自己的座位。 → 你剛剛才被大家笑，心裡還亂糟糟的。

### 週三（你注意到：阿凱）

- 一瞥：下午彩排進場舞，阿凱站在最前面帶大家跳，跳完大家都拍手了。
  - 跟大家一起用力拍手。 → 掌聲好大，阿凱笑得有點不好意思。
  - 大聲喊：「阿凱，帥喔！」 → 阿凱轉頭看過來，笑得好開心。
  - （沒做）跟著拍子，默默踏步。 → 今天不用躲誰，你覺得踏步也很好玩。

### 週四（你注意到：小晴）

- 一瞥：放學前，你看見小晴坐在位子上，很專心地翻著恐龍百科。
  - 經過她旁邊時，把腳步放輕。 → 小晴沒有被吵到，又翻了一頁。
  - 在她看得到的地方，比一個讚。 → 小晴看了你的手一眼，又低頭看書。
  - （沒做）抱著書包，快步走過去。 → 你心裡還想著那張不能畫的海報。

### 週六（你注意到：品妤）

- 一瞥：第六棒的品妤從阿凱手中接過棒子，一路往前衝。
  - 大聲喊：「品妤，衝啊！」 → 你的聲音混在加油聲裡，品妤跑得好快。
  - 跟著大家一起拍手。 → 掌聲好大，你覺得自己也是隊伍的一份子。
  - （沒做）坐下來喘氣，看著跑道。 → 你剛跑完第一棒，腿還在抖，心裡卻好輕。

## 小雨

### 週一（你注意到：阿凱）

- 一瞥：倒垃圾時，你看見阿凱對著走廊的窗戶練舞，幾個男生在旁邊笑他。
  - 走過時小聲說：「你的拍子好準。」 → 阿凱愣了一下，看著你走過去。
  - 經過那群男生時，一點都沒有笑。 → 你走過去的時候，臉上沒有一點笑。
  - （沒做）拉高拉鍊，提著垃圾桶快步走過。 → 你的外套剛被笑，你不想被任何人注意。

### 週三（你注意到：小晴）

- 一瞥：彩排進場舞時，小晴幫阿凱數拍子，一拍都沒有數錯。
  - 跟著小晴的拍子，一起數一、二、三、四。 → 第二次，大家跳得整整齊齊。
  - 跳完跟小晴說：「你數得好準。」 → 小晴點點頭：「每一拍都一樣長。」
  - （沒做）站在隊伍裡，專心跳自己的。 → 今天你跑了全班最快，腳步好輕。

### 週四（你注意到：品妤）

- 一瞥：午餐時，你看見品妤端著便當站在走道，不知道要坐哪裡。　💭 心裡想：她不是都跟欣儀一起吃嗎？
  - 走過她旁邊時，對她點點頭。 → 品妤也輕輕點了一下頭。
  - 把媽媽給你的小糖果，放在她桌角。 → 品妤看著糖果，小聲說：「謝謝。」
  - （沒做）拿著餐盒，走去洗手台。 → 佳佳的邀請卡剛剛跳過你，你也好難過。

### 週六（你注意到：阿明）

- 一瞥：比賽前，大家圍成一圈，跟著阿明用越南話喊「Cố lên！」
  - 跟著大家大聲喊：「Cố lên！」 → 你的發音怪怪的，阿明笑著對你比讚。
  - 喊完跟阿明說：「這句好好聽。」 → 阿明說：「你也喊得很好！」
  - （沒做）摸摸號碼布上的金色閃電。 → 你看著被大家圍著的阿明，替他高興。
