# 給協作 AI：《五年三班大隊接力》新角色擴充簡報

## 這份文件要請你做什麼

這是一款國小高年級（10–12 歲）的反霸凌體驗遊戲。玩家以第一人稱扮演一個被同學欺負的孩子，度過運動會前的一個禮拜。目前有三個角色（阿哲、小雨、阿明），我們想增加更多角色，讓不同背景的孩子都有機會被看見：**男生、女生、特教生、性別氣質不符合刻板印象的孩子，以及普通的學生**。

請你：

1. 評估下面「第四節」的新角色構想：哪些適合、哪些有風險、有沒有遺漏的重要族群。
2. 針對你認為適合的角色，寫出**五天的劇情大綱**（每天：場景、發生什麼事、誰在場、主角的三個選擇）。
3. 指出任何可能造成刻板印象、二度傷害或模仿風險的地方，並提出修改。

**格式要求**：請依照「第三節」的劇本格式和數值範圍。你不需要寫程式，用條列的文字寫出結構即可，我們會轉成程式並用自動化測試驗證。

文件後半附上三個現有角色的**完整劇本**，請先讀完，了解語氣、長度和設計方式。

## 一、不能違反的設計原則

這些原則來自兩輪外部審查，每一條都有自動化測試把關。新角色必須全部符合。

1. **第一人稱，但開場不說破**：玩家扮演被欺負的孩子，但標題畫面只說「選一個同學，過他的一週」。
2. **欺負的人和旁觀者的行為是固定的**：玩家的選擇只改變主角自己的感受、以及他找誰說，**不能決定他有沒有被欺負**，也不能讓霸凌變輕或變重。
3. **絕對不能傳達「被欺負是受害者的錯」或「你應該更勇敢」**。
4. **說不出口**：心靈能量太低時，有些選項會被劃掉，標示「（你現在說不出口）」，並顯示主角**心裡具體在怕什麼**（`fear`）。說不出口是因為處境太難，不是因為不夠勇敢。
5. **向大人求助的門檻要低**（能量 20–30），求助不能是英雄行為。
6. **週五早上，老師一定會自己察覺並私下找主角談**，不取決於主角有沒有說。老師的處理方式：先個別晤談、承諾保密，再對全班做**不點名**的提醒（符合《校園霸凌防制準則》113 年 4 月修正版以預防及輔導為原則）。主角如果有告訴家人，只是多一份家人的支持。
7. **老師在場時，一定當場制止歧視或侮辱性用語**。老師不在場時的霸凌（下課、走廊、群組）才是主要的霸凌場景。
8. **禁用詞**：不使用「外籍新娘」等歧視詞彙。需要呈現侮辱時，用綽號或嘲笑的行為呈現，不要讓遊戲變成教孩子新的罵人字眼。
9. **每個故事都要有一位普通同學的小善意**（不是只有弱勢角色互相幫忙）。
10. **只有一個結局**：運動會當天，欺負的人和旁觀者在每條路徑都一樣。前面的選擇只透過旗標加入細節（例如有告訴媽媽，媽媽就在觀眾席喊加油）。結局一定有一位朋友的肯定，以及一位大人約好「下禮拜再聊」。
11. **角色不能只有悲慘**：每個主角都要有優點和自己的力量（阿哲會畫畫、小雨跑很快又會照顧弟弟、阿明會兩種語言）。家庭描寫要有溫暖的一面，避免「貧窮／單親就一定很淒涼」的刻板印象。
12. **語言**：台灣國小五、六年級學生的口語。台詞簡短，一句 40 字以內。

## 二、遊戲的世界觀與固定角色

- **五年三班**準備週六運動會的**大隊接力**，全班每個人都要跑。
- **志豪**：常帶頭開玩笑、取綽號。結局後會揭露他四年級時也被笑過，以及他的自省（「這不是藉口。欺負別人，是我做錯了」）。新角色的故事裡，帶頭的人預設也是志豪；如果要換人，請說明理由。
- **佳佳**：班長，常常看到但沒說話。
- **林老師**：導師，週五一定介入。
- **各主角的家人**：每個主角有自己的媽媽（或其他家人），週四晚餐是和家人相處的場景。
- **三個現有主角會互相客串**：例如小雨的故事裡，週五是阿哲主動來找她。新角色也可以客串、或被客串。

## 三、劇本格式與數值

每個角色是一個資料檔，結構如下（請用文字條列寫出同樣的結構即可）：

- **每天開頭**：`day`（週一～週五）、`title`（標題）、`bg`（場景：`classroom` 教室、`track` 操場、`home` 家裡）、`recap`（一句摘要，第三人稱，給結尾「換你想一想」用）、`help`（四個旁觀同學那天可以做的小行動，每個附上做了之後發生的事）。
- **台詞**：`speaker`（說話的人）、`text`（台詞）、`inner`（選填，主角心裡真正的想法）、`effect`（選填，數值變化）。
- **選擇**：每天一個，三個選項。每個選項有：`text`、`need`（選填，需要的能量）、`fear`（有 `need` 時必填）、`effect`、`flag`（選填，例如 `toldMom`）、`then`（選了之後的台詞）。
- **條件劇情**：`if: 旗標` → 只有在旗標成立時出現的台詞。

**數值範圍**（新角色請沿用，才能維持平衡）：

| 項目 | 數值 |
|---|---|
| 起始能量 | 60（最高 100） |
| 每天早上 | +5 |
| 被欺負的事件 | −10 ～ −15 |
| 忍耐、退縮、自貶的選項 | −5 ～ −10 |
| 小善意 | +5 |
| 週五老師私下談話 | +10 |
| 週五同學主動來找 | +20 |
| 告訴家人 | +15（週五再 +5） |
| 對抗霸凌者的選項 | `need` 45–55 |
| 向大人求助的選項 | `need` 20–30 |
| 「看到卻沒說話」 | 以人次計，例如 `witness: 6` |

**自動化測試會檢查**：不會卡關（每個選擇至少有一個選項可選）、只有刻意設計的選項會在每條路徑都被劃掉、告訴家人在至少 25% 的路徑可選、結局固定內容在每條路徑都相同、週五老師一定介入、結局一定有老師的約定、不出現禁用詞、每天都有摘要和小行動。

## 四、新角色構想（請評估、修改、補充）

目前三個角色是兩個男生、一個女生，涵蓋 ADHD 特質、單親經濟弱勢、新住民二代。以下是我們想新增的方向：

### 1. 阿凱（男生，性別氣質不符合刻板印象）

- **特質**：喜歡跳舞、說話輕聲、和女生比較玩得來。
- **優點**：舞跳得很好，運動會開幕表演被老師找去示範。
- **霸凌類型**：取綽號（例如「娘娘腔」）、男生小團體排擠、更衣或分組時被刻意避開。
- **劇情方向**：週一在走廊練舞被看到；週二體育課男生分組沒人要他；週三……
- **需要注意**：依《性別平等教育法》，針對性別特徵或性別氣質的霸凌可能屬於「性霸凌」，學校的處理流程和一般霸凌不同（由性平會處理）。請確認劇情中老師的處理方式正確。綽號要不要直接出現在畫面上，請提出建議。

### 2. 小晴（女生，自閉症類群，特教生）

- **特質**：不太懂玩笑和反話、對大聲音很敏感、有固定的習慣（例如鉛筆一定要排整齊）、對恐龍知識非常厲害。部分課程在資源班上。
- **優點**：記憶力驚人，記得全班每個人的生日。
- **霸凌類型**：被模仿說話方式、被故意弄出大聲音嚇她、被說「她去資源班的」、被利用（叫她做奇怪的事看她會不會照做）。
- **需要注意**：描寫要尊重神經多樣性，避免把她寫成「可憐」或「怪」。她的內心話怎麼寫才真實？哪些情境對特教生來說最常見？

### 3. 品妤（女生，普通學生）

- **特質**：成績普通、個性普通，原本是旁觀者之一。
- **劇情方向**：週一她替阿明說了一句話，之後被她原本的小團體排擠、在群組被已讀不回、午餐時座位被佔走。
- **想傳達的**：任何人都可能被針對；也呈現挺身而出後可能面對的真實壓力。
- **需要注意**：這個故事**不能讓孩子學到「挺身而出會倒楣，所以不要幫別人」**。要怎麼設計，才能同時誠實又不打擊旁觀者介入？

### 4. 其他候選（請評估優先順序）

- **轉學生**：口音、不熟悉班上規則、沒有朋友。
- **體型**：被取跟體型有關的綽號、體育課被嘲笑。
- **學習障礙（讀寫困難）**：唸課文很慢被笑、作業寫得很辛苦。
- **聽障（戴助聽器）**：聽不清楚被說「裝傻」、助聽器被拿走。
- **原住民學生**：名字、膚色、文化被開玩笑。
