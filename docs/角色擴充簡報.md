# 給協作 AI：《五年三班大隊接力》新角色擴充簡報

## 這份文件要請你做什麼

這是一款國小高年級（10–12 歲）的反霸凌體驗遊戲。玩家以第一人稱扮演一個被同學欺負的孩子，度過運動會前的一個禮拜。目前有三個角色（阿哲、小雨、阿明），我們想增加更多角色，讓不同背景的孩子都有機會被看見：**男生、女生、特教生、性別氣質不符合刻板印象的孩子，以及普通的學生**。

請你：

1. 評估下面「第四節」的新角色構想：哪些適合、哪些有風險、有沒有遺漏的重要族群。
2. 針對你認為適合的角色，寫出**五天的劇情大綱**（每天：場景、發生什麼事、誰在場、主角的三個選擇）。
3. 指出任何可能造成刻板印象、二度傷害或模仿風險的地方，並提出修改。
4. 評估「第六節」的角色交織構想：讓所有角色活在同一個禮拜，玩家能用第三者的視角看到別人的事，作為進班教學小組討論的材料。
5. 設計「第八節」的自我覺察日記（每個角色五篇）和進班教學流程（前導、發展、綜合活動）。

**分工**：這份文件只請你處理**劇情與教育設計**（故事內容、日記問題、情緒詞彙、教學活動）。遊戲畫面、介面、美術和程式由我們另外處理，你不需要提出建議。

**格式要求**：請依照「第三節」的劇本格式和數值範圍。你不需要寫程式，用條列的文字寫出結構即可，我們會轉成程式並用自動化測試驗證。

文件後半附上三個現有角色的**完整劇本**，請先讀完，了解語氣、長度和設計方式。

## 一、不能違反的設計原則

這些原則來自兩輪外部審查，每一條都有自動化測試把關。新角色必須全部符合。

1. **第一人稱，但開場不說破**：玩家扮演被欺負的孩子，但標題畫面只說「選一個同學，過他的一週」。
2. **欺負的人和旁觀者的行為是固定的**：玩家的選擇只改變主角自己的感受、以及他找誰說，**不能決定他有沒有被欺負**，也不能讓霸凌變輕或變重。
3. **絕對不能傳達「被欺負是受害者的錯」或「你應該更勇敢」**。
4. **說不出口**：心靈能量太低時，有些選項會被劃掉，標示「（你現在說不出口）」，並顯示主角**心裡具體在怕什麼**（`fear`）。說不出口是因為處境太難，不是因為不夠勇敢。
5. **向大人求助的門檻要低**（能量 20–30），求助不能是英雄行為。
6. **週五早上，老師一定會自己察覺並私下找主角談**，不取決於主角有沒有說。老師的處理方式：先個別晤談、承諾保密，再對全班做**不點名**的提醒（符合《校園霸凌防制準則》113 年 4 月修正版以預防及輔導為原則）。主角如果有告訴家人，只是多一份家人的支持。
7. **老師在場時，一定當場制止歧視或侮辱性用語**。老師不在場時的霸凌（下課、走廊、群組）才是主要的霸凌場景。
8. **禁用詞**：不使用「外籍新娘」等歧視詞彙。需要呈現侮辱時，用綽號或嘲笑的行為呈現，不要讓遊戲變成教孩子新的罵人字眼。
9. **每個故事都要有一位普通同學的小善意**（不是只有弱勢角色互相幫忙）。
10. **只有一個結局**：運動會當天，欺負的人和旁觀者在每條路徑都一樣。前面的選擇只透過旗標加入細節（例如有告訴媽媽，媽媽就在觀眾席喊加油）。結局一定有一位朋友的肯定，以及一位大人約好「下禮拜再聊」。
11. **角色不能只有悲慘**：每個主角都要有優點和自己的力量（阿哲會畫畫、小雨跑很快又會照顧弟弟、阿明會兩種語言）。家庭描寫要有溫暖的一面，避免「貧窮／單親就一定很淒涼」的刻板印象。
12. **語言**：台灣國小五、六年級學生的口語。台詞簡短，一句 40 字以內。

## 二、遊戲的世界觀與固定角色

- **五年三班**準備週六運動會的**大隊接力**，全班每個人都要跑。
- **志豪**：常帶頭開玩笑、取綽號。結局後會揭露他四年級時也被笑過，以及他的自省（「這不是藉口。欺負別人，是我做錯了」）。新角色的故事裡，帶頭的人預設也是志豪；如果要換人，請說明理由。
- **佳佳**：班長，常常看到但沒說話。
- **林老師**：導師，週五一定介入。
- **各主角的家人**：每個主角有自己的媽媽（或其他家人），週四晚餐是和家人相處的場景。
- **三個現有主角會互相客串**：例如小雨的故事裡，週五是阿哲主動來找她。新角色也可以客串、或被客串。

## 三、劇本格式與數值

每個角色是一個資料檔，結構如下（請用文字條列寫出同樣的結構即可）：

- **每天開頭**：`day`（週一～週五）、`title`（標題）、`bg`（場景：`classroom` 教室、`track` 操場、`home` 家裡）、`recap`（一句摘要，第三人稱，給結尾「換你想一想」用）、`help`（四個旁觀同學那天可以做的小行動，每個附上做了之後發生的事）。
- **台詞**：`speaker`（說話的人）、`text`（台詞）、`inner`（選填，主角心裡真正的想法）、`effect`（選填，數值變化）。
- **選擇**：每天一個，三個選項。每個選項有：`text`、`need`（選填，需要的能量）、`fear`（有 `need` 時必填）、`effect`、`flag`（選填，例如 `toldMom`）、`then`（選了之後的台詞）。
- **條件劇情**：`if: 旗標` → 只有在旗標成立時出現的台詞。

**數值範圍**（新角色請沿用，才能維持平衡）：

| 項目 | 數值 |
|---|---|
| 起始能量 | 60（最高 100） |
| 每天早上 | +5 |
| 被欺負的事件 | −10 ～ −15 |
| 忍耐、退縮、自貶的選項 | −5 ～ −10 |
| 小善意 | +5 |
| 週五老師私下談話 | +10 |
| 週五同學主動來找 | +20 |
| 告訴家人 | +15（週五再 +5） |
| 對抗霸凌者的選項 | `need` 45–55 |
| 向大人求助的選項 | `need` 20–30 |
| 「看到卻沒說話」 | 以人次計，例如 `witness: 6` |

**自動化測試會檢查**：不會卡關（每個選擇至少有一個選項可選）、只有刻意設計的選項會在每條路徑都被劃掉、告訴家人在至少 25% 的路徑可選、結局固定內容在每條路徑都相同、週五老師一定介入、結局一定有老師的約定、不出現禁用詞、每天都有摘要和小行動。

## 四、新角色構想（請評估、修改、補充）

> **更新**：阿凱、小晴、品妤已經依上一輪的研究報告寫成遊戲劇本，完整內容在後半「完整劇本」。下一輪請評估這三個角色的劇本，不需要重寫。

目前三個角色是兩個男生、一個女生，涵蓋 ADHD 特質、單親經濟弱勢、新住民二代。以下是我們想新增的方向：

### 1. 阿凱（男生，性別氣質不符合刻板印象）

- **特質**：喜歡跳舞、說話輕聲、和女生比較玩得來。
- **優點**：舞跳得很好，運動會開幕表演被老師找去示範。
- **霸凌類型**：取綽號（例如「娘娘腔」）、男生小團體排擠、更衣或分組時被刻意避開。
- **劇情方向**：週一在走廊練舞被看到；週二體育課男生分組沒人要他；週三……
- **需要注意**：依《性別平等教育法》，針對性別特徵或性別氣質的霸凌可能屬於「性霸凌」，學校的處理流程和一般霸凌不同（由性平會處理）。請確認劇情中老師的處理方式正確。綽號要不要直接出現在畫面上，請提出建議。

### 2. 小晴（女生，自閉症類群，特教生）

- **特質**：不太懂玩笑和反話、對大聲音很敏感、有固定的習慣（例如鉛筆一定要排整齊）、對恐龍知識非常厲害。部分課程在資源班上。
- **優點**：記憶力驚人，記得全班每個人的生日。
- **霸凌類型**：被模仿說話方式、被故意弄出大聲音嚇她、被說「她去資源班的」、被利用（叫她做奇怪的事看她會不會照做）。
- **需要注意**：描寫要尊重神經多樣性，避免把她寫成「可憐」或「怪」。她的內心話怎麼寫才真實？哪些情境對特教生來說最常見？

### 3. 品妤（女生，普通學生）

- **特質**：成績普通、個性普通，原本是旁觀者之一。
- **劇情方向**：週一她替阿明說了一句話，之後被她原本的小團體排擠、在群組被已讀不回、午餐時座位被佔走。
- **想傳達的**：任何人都可能被針對；也呈現挺身而出後可能面對的真實壓力。
- **需要注意**：這個故事**不能讓孩子學到「挺身而出會倒楣，所以不要幫別人」**。要怎麼設計，才能同時誠實又不打擊旁觀者介入？

### 4. 其他候選（請評估優先順序）

- **轉學生**：口音、不熟悉班上規則、沒有朋友。
- **體型**：被取跟體型有關的綽號、體育課被嘲笑。
- **學習障礙（讀寫困難）**：唸課文很慢被笑、作業寫得很辛苦。
- **聽障（戴助聽器）**：聽不清楚被說「裝傻」、助聽器被拿走。
- **原住民學生**：名字、膚色、文化被開玩笑。

## 六、角色交織：同一個禮拜，從不同人的眼睛看

### 想做到什麼

所有角色活在**同一個五年三班、同一個禮拜**。玩家玩一個角色時，會在背景裡「看到」其他角色發生的事，但只是以**第三者（旁觀同學）**的視角看到。

- **不是**互相影響劇情：玩家在阿哲的故事做的選擇，不會改變小雨的故事。每個故事仍然各自獨立，也各自通過自動化測試。
- **而是**讓同一件事在不同故事裡被看見：在 A 的故事裡只是背景的一句話，在 B 的故事裡卻是整天的主線。

這樣做的原因是**進班教學**。全班分組，每組的人玩不同角色，玩完再一起拼出「這個禮拜五年三班到底發生了什麼」，小組討論才有內容可以談。

### 現有劇本已經有的交織（可以當範例）

| 在誰的故事裡 | 看到了什麼（第三者視角） | 在誰的故事裡是主線 |
|---|---|---|
| 阿哲・週二 練跑 | 「佳佳低頭看著碼錶，小雨看著地上，阿明假裝在綁鞋帶。」三個人都沒說話 | 小雨、阿明自己那週也正在被欺負 |
| 阿明・週二 午餐 | 小雨坐在旁邊，看了阿明的便當一眼，又低下頭 | 小雨的故事裡，她自己也在為錢、為外套難過 |
| 阿哲・週五 | 阿明來問「你還好嗎？」，說自己被叫「外星阿明」 | 阿明的週一 |
| 小雨・週五 | 阿哲說要在號碼布畫閃電，提到「跟我同一隊很倒楣」 | 阿哲的週二 |
| 阿明・週五 | 小雨問那句越南話是什麼意思，提到外套被笑 | 小雨的週一、週二 |

目前的交織都是「被欺負的孩子互相扶持」。**第九條原則要求的「普通同學的小善意」**，可以讓它在不同故事裡也是同一個人（例如：在阿哲的故事遞金色彩色筆的同學，就是在小雨的故事私訊「我沒有笑」的那個人），讓學生發現「那個普通同學，其實幫了不只一個人」。

### 交織時必須先解決的一致性問題

把故事放在同一條時間軸上之後，目前有一個衝突：

- **週五放學**（**已修正**）：原本阿哲和阿明都「一個人留在操場收接力棒」。現在阿哲在跑道終點收接力棒，阿明在器材室門口收角錐。
- 建議解法（請評估）：把三個故事的週五場景放到不同時間地點（例如阿哲是放學後的操場、阿明是午休的教室、小雨是下午練跑），或乾脆讓三個人的週五在同一個場景交會，每個故事只呈現自己那一段。

### 遊戲裡可以怎麼呈現（構想，請評估）

1. **背景一瞥**：每個故事每天加一句旁白，讓玩家用第三者的眼睛看到另一個角色的那件事。玩家無法介入，只會留下一句心裡的想法（例如「她為什麼一直拉著外套拉鍊？」）。
2. **結尾的「同一天，在別人眼中」**：結局之後加一頁，選一天，對照「你那天看到的」和「那天對另一個人來說是什麼樣子」。例如玩完阿哲：「週二，你看到小雨一直看著地上。那天晚上，她的外套照片被傳到群組，24 人已讀。」
3. **解鎖其他角色的視角**：玩完一個角色後，選角畫面標示「你在這個故事裡見過他」。

### 進班教學：小組討論怎麼設計（構想，請評估）

- **拼圖式分組**：三人一組，每人玩不同角色（約 15 分鐘），再回到小組，用共用時間軸拼出全班的這一週。
- **討論問題範例**：
  - 你玩的角色，在別人的故事裡出現過嗎？那時候別人看到的你，和你自己的感受一樣嗎？
  - 有沒有一個時刻，三個故事裡都有人「看到了，卻沒有說話」？如果你是那個人，你可以做什麼小事？
  - 那位普通同學做了什麼？為什麼一件很小的事，在被欺負的人眼裡很大？
- **一定要注意**：
  - 角色由學生**自己選**，不要指定，避免讓班上真的被欺負的孩子被對號入座。
  - 討論只談故事裡的角色，不談班上真實的人。
  - 不比較「誰的心靈能量比較高」，遊戲本來就不給分數。
  - 結束前回到「如果你在現實生活中遇到類似的事」那一頁，並說明可以私下找老師。
- **需要你幫忙的**：一份老師用的帶領指引（時間分配、提問順序、遇到學生情緒反應時怎麼辦）和一張學生用的時間軸學習單。

## 七、關於交織，我們想問你的問題

1. 「第三者視角的背景一瞥」會不會讓故事太亂？每天加一句是適合的量嗎？

3. 新角色要怎麼排進共用時間軸，才能和現有三個人自然交會，又不搶走他們的主線？
4. 讓同一位「普通同學」在不同故事裡都出現，這個設計好嗎？他應該是誰？
5. 小組討論的問題，怎麼問才能讓孩子談旁觀者的責任，又不會變成指責？

## 八、自我覺察日記與進班教學流程

### 為什麼要加日記

社會情緒學習（SEL）很重視**自我覺察**：認出自己的情緒、說出它的名字、知道它從哪裡來。目前遊戲只在結尾用「心裡的天氣」回顧一週，玩家在過程中沒有機會停下來想自己的感受。

### 日記的構想

- **每個角色五篇**：週一到週五，每天的劇情結束後寫一篇（週六運動會是結局，不寫）。
- **以角色的身分寫**：例如「我是阿哲，今天……」。玩家透過角色覺察情緒，不直接要求寫自己的真實經驗。
- **每篇的步驟**：
  1. **情緒象限**：兩個軸，「舒服 ↔ 不舒服」×「能量高 ↔ 能量低」，玩家先點今天的心情在哪一格。
  2. **命名情緒**：從那一格的情緒詞裡挑一個，或**自己寫一個詞**。重點是讓學生練習用自己的話說出情緒，不只是選「開心／難過」。
  3. **一到兩個引導問題**：配合當天的劇情，例如「今天哪一刻最難受？」「你希望誰注意到？」。
- 遊戲**不評分、不判斷對錯**，任何情緒都可以。
- 日記的輸出與收集不在遊戲裡實作（會寫在論文中說明）。

### 進班教學流程（一節或兩節課）

1. **前導活動（引起動機）**：在進遊戲前暖身，例如討論「你看過別人被開玩笑，但對方笑不出來的時候嗎？」，或先認識情緒象限和情緒詞。
2. **發展活動（主要活動）**：
   - 分組，每組的人各選一個角色（由學生自己選，不指定）。
   - 玩完一週，寫完五篇日記。
   - 小組內對照：同一天，不同角色的日記寫了什麼？你在別人的故事裡看到的他，和他自己寫的一樣嗎？（搭配第六節的角色交織）
3. **綜合活動（統整分享）**：
   - **每組上台分享**，全班都看得到每一組的想法。
   - 聽完別組之後，每個人**再做一次決定**：例如重新選「換你想一想」的那一天、那件小事，或寫一句「聽完別組的分享，我的想法變成……」。
   - 重點是讓學生看到：聽了別人的想法，自己可能會有新的決定。
   - 最後回到「如果你在現實生活中遇到類似的事」那一頁。

### 遊戲裡已經做好的部分（內容是暫定的，請你替換）

日記和「聽完分享，再想一次」的畫面已經做好，但下面的內容是我們先放的暫定版本：

- **情緒象限四格**（每格一個名稱、一句「像是……」的例子、八個詞；名稱改成孩子比較容易對上的說法）：
  - 左上「生氣緊張」（能量高、不舒服）：生氣、委屈、緊張、丟臉、煩躁、害怕、不甘心、防備
  - 右上「開心有勁」（能量高、舒服）：開心、期待、興奮、驕傲、感動、有勇氣、被支持、躍躍欲試
  - 左下「難過低落」（能量低、不舒服）：難過、受傷、孤單、沮喪、失落、無能為力、想哭、被冷落
  - 右下「平靜安心」（能量低、舒服）：安心、溫暖、輕鬆、踏實、鬆了一口氣、被理解、滿足、被接納
- **每天通用的引導問題**（所有角色共用，每天一題）：
  - 週一：今天哪一刻，你心裡最不舒服？那時候你在想什麼？
  - 週二：今天有人看到發生的事嗎？你希望他們怎麼做？
  - 週三：如果可以對今天的某個人說一句話，你想說什麼？
  - 週四：今天晚上，有沒有什麼話你想說，卻沒有說出口？
  - 週五：今天有沒有哪一刻，讓你覺得好一點？是因為誰？
- **格式**：每個角色每天可以有自己的引導問題（一到兩題），寫在那天的開頭，例如「`diary`：今天大家笑你『過動兒』的時候，你心裡在想什麼？」。沒有寫的話就用上面的通用問題。

### 請你幫忙設計

1. 每個角色每天的**日記引導問題**（3 個角色 × 5 天），要配合當天的劇情，並且是 10–12 歲寫得出來的問題。
2. **情緒象限的詞彙**：四格各放哪些適合國小高年級的情緒詞（每格約 6–8 個），要比「開心／難過」更細，但孩子看得懂。
3. 允許學生**自己命名情緒**時，介面上怎麼引導，才不會只寫「還好」「不知道」？
4. **前導活動**和**綜合活動**的具體設計：時間分配、提問、上台分享的形式（每組報告什麼、用什麼呈現）。
5. 綜合活動的「**再決定一次**」怎麼設計，才能看出學生聽完分享後想法的改變？
6. 日記會不會讓某些孩子太難受？需要哪些安全設計（例如可以跳過、可以只選象限不寫字）？
